Deployment check

Runs every case below and checks each outcome. The timeout case exits a worker and waits for the platform to restart it and redeliver, so a full run takes one to two minutes.

Load tests

One load run per environment. Pairs run sequentially. Memory and OOM presets put real pressure on the selected cluster.

Cancel stops dispatch and makes queued jobs no-op; work already running finishes. Holds are per web process and free memory automatically.

DB async uses up to 5 connections per job (20 across 4 workers), disposed after each job. DB sync uses 1 connection per worker. Read tests use 1000 fixed, indexed benchmark rows.

OOM events are best-effort: cgroup counters can reset after a restart. Failed jobs, including lost jobs, are the reliable failure signal during OOM tests.
